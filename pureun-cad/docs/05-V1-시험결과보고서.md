# 05. V1 시험 결과 보고서 — 푸른캐드 V1 (사용성 업그레이드)

- 시험일: 2026-11-27 · 이전 버전 보고서: [04-시험결과보고서.md](04-시험결과보고서.md)(V0)
- 시험 환경: V0와 같음(Linux 컨테이너, headless Chromium, Node 22, ezdxf 1.4.5). **실제 AutoCAD·실사용자 평가는 하지 못했습니다.**

## 1. V1 변경 범위

사용자 요청 "사용성·편의성을 모두 갖춘 상용급 CAD"에 따라, AutoCAD 사용자가 매일 쓰는 조작을 우선 구현했습니다. 상용 CAD 전체와 같은 범위는 아니며, 남은 항목은 6장에 있습니다.

| 분류 | 항목 |
|---|---|
| 조작 편의 | 그립 편집, 동적 입력 툴팁(F12), 극좌표 추적(F10, 5~90°), 명령 자동완성·한글 명령명, 오른쪽 클릭 바로가기 메뉴, 두 번 클릭 문자 편집, 사용자 별칭(acad.pgp 형식), 빠른 선택(QSELECT) |
| 편집 명령 | MIRROR, SCALE, STRETCH, EXTEND, FILLET(선-선), CHAMFER(선-선), BREAK, JOIN, EXPLODE(폴리선·치수·블록 참조), ARRAY(원형·직사각형) |
| 가공 도구 | OVERKILL(중복·겹친 선 정리), CAMCHECK(열린 끝점·열린 폴리선·길이 0·중복 검사) |

### 2.1 V1 단위 시험 (tests/unit/edit.test.ts)
- MIRROR: Y축 대칭 시 호 각도 (0°~90° → 90°~180°), 폴리선 bulge 부호 반전
- SCALE: 원 중심·반지름 2배
- EXTEND: 선→수직선, 선→원, 호→선 경계, 경계 없음 오류
- FILLET: 직각 R5(접점 5, 중심 (5,5), 호 180°~270°), R0 모서리 맞춤, 반지름 과다 오류 / CHAMFER C3
- JOIN: 방향이 섞인 4선 → 닫힌 폴리선(둘레 40), 선+호 → 폴리선(길이 10+5π) → EXPLODE 복원
- BREAK: 선 가운데, 원 반시계 구간
- ARRAY: PCD150 원형 8개(원본 포함), 직사각형 3×4
- OVERKILL: 역방향 중복선·포함된 겹친 선 / CAMCHECK: 열린 끝점 2, 길이 0 검출
- STRETCH: 창 안 끝점·정점만 이동
- 별칭: pgp 형식 적용·오류 보고, 한글 명령명, 자동완성 순위

### 2.2 V1 화면 시험 (tests/e2e/run-e2e.cjs, V0 시나리오 20개 + V1 7개)
1. 자동완성 "FI" → 목록에 FILLET, Tab 실행 / 한글 "모깎기" 실행
2. 그립 편집: 선 끝점 그립 클릭 → `@10,0` → (60,0), 실행취소 복원
3. FILLET R5 마우스 선택 → 중심 (5,5) / 원형 배열 8개 / MIRROR 복사
4. 극좌표 추적: 30.6° 방향 커서 → 정확히 30.000…° 위의 점
5. 두 번 클릭 문자 편집(기존 문자 미리 채움) · 오른쪽 클릭 메뉴 항목 · 동적 입력 툴팁 표시
6. STRETCH: 사각형 오른쪽 변 10 늘림 → 정점 정확
7. CAMCHECK 중복 1개 보고 → OVERKILL 후 1개 남음

화면 캡처: `tests/e2e/out/dyninput.png`(동적 입력·극좌표 추적선), `contextmenu.png`(그립·바로가기 메뉴).

## 3. V1 독립 코드 검토와 조치

구현자와 분리된 검토자(별도 AI 검토 에이전트 — 외부 전문가 승인 아님)가 V1 신규 코드를 읽고 재현 시험으로 8건을 지적했습니다. 모두 수정했고 `tests/unit/regressions-v1.test.ts`로 재발을 막았습니다.

| # | 심각도 | 지적 | 조치 |
|---|---|---|---|
| 1 | 높음 | BREAK에서 `@`(같은 점에서 나눔)가 이전 명령의 마지막 점을 써서 객체 일부가 사라짐 | 첫 번째 끊는 점을 기준점(@)으로 지정 |
| 2 | 높음 | OVERKILL이 다른 레이어의 겹친 선, 선종류·색상·폭만 다른 객체를 중복으로 지움 | 레이어·색상·선종류가 같을 때만 중복, 폭 있는 폴리선은 판정 제외 |
| 3 | 중상 | 블록 분해(EXPLODE→B)가 대칭 블록의 호를 다각선으로 근사, MINSERT 100개 초과분·블록 안 POINT 등을 잃고 원본 삭제 | 대칭 블록 호를 정확한 호로 변환, 근사·손실이 생기는 블록은 분해하지 않고 원본 유지 + 사유 보고 |
| 4 | 중 | SCALE 미리보기와 실제 결과 배율 불일치 | 미리보기를 실제 계산과 같게 |
| 5 | 중 | 문자 두 번 클릭 시 두 번째 클릭이 그립 편집을 시작해 문자 편집 불가 | 두 번 클릭 시 그립 편집 취소 후 문자 편집 |
| 6 | 중하 | JOIN·SCALE·ARRAY에서 폴리선 폭(40/41/43) 손실·미반영 | 이동·회전·배열에서 폭 유지, 축척에 비례, 같은 폭이면 결합 후 유지 |
| 7 | 중하 | STRETCH에서 한쪽 끝만 창 안인 호가 그대로 남아 윤곽이 벌어짐 | 사이각을 유지한 채 새 끝점을 지나는 호로 다시 계산(이웃과 연결 유지), 끝점이 창 밖이면 이동하지 않음 |
| 8 | 낮음 | 간격 0·각도 조합으로 같은 위치 중복 배열, 중복 정점 폴리선 분해 시 길이 0 선, 사용자 별칭 `U` 무시, 치수 편집 안내 문구 | 배열 입력 검사(최대 100,000), 분해 전 중복 정점 제거, 사용자 별칭 우선, 문구 수정 |

검토자가 "정상"으로 확인: 대칭(호 각도·bulge), 모깎기(예각·둔각·교차·비교차, 반지름 과다/평행 오류), 모따기, 결합(역방향 호 bulge), 분해(음의 sweep 호), 연장(0° 경계), 끊기(원·닫힌 폴리선), 원형 배열, 모든 신규 명령의 잠금·꺼짐 레이어 보호, 실행취소 묶음, 극좌표 0/90/180/270° 정확값, 사용자 별칭, OVERKILL 속도(2만 선 80ms).
