## 1. V1 변경 범위

사용자 요청 "사용성·편의성을 모두 갖춘 상용급 CAD"에 따라, AutoCAD 사용자가 매일 쓰는 조작을 우선 구현했습니다. 상용 CAD 전체와 같은 범위는 아니며, 남은 항목은 6장에 있습니다.

| 분류 | 항목 |
|---|---|
| 조작 편의 | 그립 편집, 동적 입력 툴팁(F12), 극좌표 추적(F10, 5~90°), 명령 자동완성·한글 명령명, 오른쪽 클릭 바로가기 메뉴, 두 번 클릭 문자 편집, 사용자 별칭(acad.pgp 형식), 빠른 선택(QSELECT) |
| 편집 명령 | MIRROR, SCALE, STRETCH, EXTEND, FILLET(선-선), CHAMFER(선-선), BREAK, JOIN, EXPLODE(폴리선·치수·블록 참조), ARRAY(원형·직사각형) |
| 가공 도구 | OVERKILL(중복·겹친 선 정리), CAMCHECK(열린 끝점·열린 폴리선·길이 0·중복 검사) |

### 2.1 V1 단위 시험 (tests/unit/edit.test.ts)
- MIRROR: Y축 대칭 시 호 각도 (0°~90° → 90°~180°), 폴리선 bulge 부호 반전
- SCALE: 원 중심·반지름 2배
- EXTEND: 선→수직선, 선→원, 호→선 경계, 경계 없음 오류
- FILLET: 직각 R5(접점 5, 중심 (5,5), 호 180°~270°), R0 모서리 맞춤, 반지름 과다 오류 / CHAMFER C3
- JOIN: 방향이 섞인 4선 → 닫힌 폴리선(둘레 40), 선+호 → 폴리선(길이 10+5π) → EXPLODE 복원
- BREAK: 선 가운데, 원 반시계 구간
- ARRAY: PCD150 원형 8개(원본 포함), 직사각형 3×4
- OVERKILL: 역방향 중복선·포함된 겹친 선 / CAMCHECK: 열린 끝점 2, 길이 0 검출
- STRETCH: 창 안 끝점·정점만 이동
- 별칭: pgp 형식 적용·오류 보고, 한글 명령명, 자동완성 순위

### 2.2 V1 화면 시험 (tests/e2e/run-e2e.cjs, V0 시나리오 20개 + V1 7개)
1. 자동완성 "FI" → 목록에 FILLET, Tab 실행 / 한글 "모깎기" 실행
2. 그립 편집: 선 끝점 그립 클릭 → `@10,0` → (60,0), 실행취소 복원
3. FILLET R5 마우스 선택 → 중심 (5,5) / 원형 배열 8개 / MIRROR 복사
4. 극좌표 추적: 30.6° 방향 커서 → 정확히 30.000…° 위의 점
5. 두 번 클릭 문자 편집(기존 문자 미리 채움) · 오른쪽 클릭 메뉴 항목 · 동적 입력 툴팁 표시
6. STRETCH: 사각형 오른쪽 변 10 늘림 → 정점 정확
7. CAMCHECK 중복 1개 보고 → OVERKILL 후 1개 남음

화면 캡처: `tests/e2e/out/dyninput.png`(동적 입력·극좌표 추적선), `contextmenu.png`(그립·바로가기 메뉴).
