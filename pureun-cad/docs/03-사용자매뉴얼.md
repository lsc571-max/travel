# 03. 사용자 매뉴얼 — 푸른캐드 V0

AutoCAD에 익숙한 분이 바로 쓸 수 있도록 명령어·별칭·좌표 입력 방식을 AutoCAD와 같게 맞췄습니다. 단위는 mm 기준입니다.

## 1. 시작하기

- 웹 브라우저(Chrome·Edge 최신 권장)에서 배포 주소를 엽니다. 한 번 연 뒤에는 인터넷 없이도 실행됩니다(https 배포 시).
- PC에서 직접 실행: `pureun-cad` 폴더에서 `npm install` → `npm run build` → `npm run preview` 후 표시된 주소(예: http://localhost:4173)를 엽니다.
- 도면은 이 PC의 브라우저 안에만 자동 저장되며 외부 서버로 전송되지 않습니다. 다시 열면 "자동 저장 도면 복구"를 물어봅니다.

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 메뉴 | 파일·편집·그리기·수정·치수·도구·보기·도움말, 오른쪽에 파일 이름·공유·설정 버튼 |
| 도구 모음 | 자주 쓰는 명령 아이콘(마우스를 올리면 이름과 별칭 표시), 현재 레이어 선택 |
| 작업 영역 | 도면. 십자 커서, 스냅 표시(□끝점 △중간점 ○중심점 ×교차점 ◇사분점) |
| 오른쪽 속성 창 | 선택한 객체의 레이어·색상·선종류·좌표·길이·면적 등 확인·수정 |
| 하단 명령창 | 명령 기록, 현재 프롬프트(옵션은 클릭 가능), 입력칸 |
| 상태 표시줄 | 커서 좌표, 스냅(F3)·직교(F8)·그리드(F7), 선택 개수, 단위, 버전 |

## 3. 기본 조작

| 조작 | 동작 |
|---|---|
| 명령 입력 | 작업 영역에서 그냥 타자를 치면 명령창으로 들어갑니다. Enter 또는 Space로 실행 |
| Enter / Space / 오른쪽 클릭 | 입력 확정. 명령이 없을 때는 **직전 명령 반복** |
| Esc | 명령 취소, 선택 해제 |
| 마우스 휠 | 커서 위치 기준 확대/축소 |
| 가운데 버튼 드래그 / 두 번 클릭 | 화면 이동 / 전체 보기 |
| 왼쪽→오른쪽 드래그(또는 두 번 클릭) | 창 선택: 완전히 들어간 객체만 |
| 오른쪽→왼쪽 드래그 | 걸치기 선택: 걸친 객체 포함 |
| Shift + 클릭/드래그 | 선택에서 빼기 |
| Delete | 선택한 객체 지우기 |
| Ctrl+Z / Ctrl+Y | 실행취소 / 다시실행 |
| Ctrl+A / Ctrl+S / Ctrl+O | 전체 선택 / 저장 / 열기 |
| ↑ ↓ (명령창) | 이전 입력 불러오기 |

## 4. 좌표 입력

| 입력 예 | 의미 |
|---|---|
| `100,50` | 절대 좌표 (X=100, Y=50) |
| `#100,50` | 절대 좌표(명시) |
| `@20,0` | 마지막 점에서 X로 20 |
| `@50<30` | 마지막 점에서 거리 50, 각도 30°(오른쪽 기준 반시계 +) |
| `50<30` | 원점에서 거리 50, 각도 30° |
| `35` (숫자만) | **직접 거리 입력**: 커서가 가리키는 방향으로 35. 직교(F8)와 함께 쓰면 편리 |
| `@` | 마지막 점과 같은 점 |

## 5. 명령어 목록

### 그리기
| 명령 | 별칭 | 사용법 |
|---|---|---|
| LINE | L | 점을 차례로 지정. `U` 마지막 선분 취소, `C` 닫기, Enter 종료 |
| CIRCLE | C | 중심 → 반지름(숫자 또는 점). `D` 지름, `2P` 두 점, `3P` 세 점 |
| ARC | A | 시작점 → 두 번째 점 → 끝점(3점). `C` 중심 → 시작점 → 끝점(반시계) |
| PLINE | PL | 점 지정. `A` 호 모드(접선 원호), `L` 선 모드, `C` 닫기, `U` 취소. Esc로 끝내도 그린 부분 유지 |
| RECTANG | REC | 첫 구석 → 다른 구석(예: `@100,50`). 닫힌 폴리선 생성 |
| TEXT | DT | 시작점 → 높이 → 회전 → 문자 입력(Enter마다 다음 줄, 빈 줄로 종료). `%%c`=Ø, `%%d`=°, `%%p`=± |

### 수정
| 명령 | 별칭 | 사용법 |
|---|---|---|
| MOVE | M | 객체 선택 → 기준점 → 두 번째 점. 먼저 선택해 두고 실행해도 됨 |
| COPY | CO, CP | 객체 선택 → 기준점 → 두 번째 점(여러 번), Enter 종료. 실행취소 1회로 전체 취소 |
| ROTATE | RO | 객체 선택 → 기준점 → 각도(숫자 또는 점). `C` 복사 모드 |
| TRIM | TR | 자를 부분을 클릭(빠른 모드: 모든 객체가 경계). `B` 경계 직접 선택, `U` 직전 자르기 취소. 교차하는 경계가 없으면 **지우지 않고** 안내만 합니다 |
| OFFSET | O | 거리(또는 `T` 통과점) → 객체 클릭 → 띄울 쪽 클릭(반복). 반지름 초과·자기교차 등 계산 불가 시 오류 표시 후 원본 유지 |
| ERASE | E | 객체 선택 → Enter |
| UNDO / REDO | U, Ctrl+Z / Ctrl+Y | 명령 단위 실행취소(최대 200단계) / 다시실행 |

### 치수·측정
| 명령 | 별칭 | 사용법 |
|---|---|---|
| DIMLINEAR | DLI | 두 점(또는 Enter → 선 선택) → 치수선 위치. 커서 위치로 수평/수직 자동, `H`/`V` 강제, `T` 문자 재지정(`<>`=측정값) |
| DIMALIGNED | DAL | 두 점 → 치수선 위치 (두 점 방향과 평행) |
| DIMDIAMETER | DDI | 원/호 선택 → 문자 위치. "Ø값" |
| DIMRADIUS | DRA | 원/호 선택 → 문자 위치. "R값" |
| DIST | DI | 두 점 → 거리, X·Y 증분, 각도 |
| ID | ID | 점 → 좌표 |
| LIST | LI, LS | 객체 → 길이·면적·반지름·중심·정점 수 등 |

### 기계가공·관리
| 명령 | 별칭 | 사용법 |
|---|---|---|
| HOLEDIA | HD | **동일 지름 원 일괄 변경**. 도면의 원을 지름별로 묶어 개수 표시 → 지름 선택(원을 하나 선택한 뒤 실행하면 자동 선택) → "도면에서 선택 표시"로 확인 → 새 지름 입력 → 일괄 변경. 중심 좌표는 그대로, 잠긴·꺼진 레이어의 원은 제외, 실행취소 1회로 되돌림. 판정 허용오차는 설정에서 변경(기본 0.0001mm) |
| LAYER | LA | 레이어 관리: 새 레이어, 이름 변경(더블클릭), 삭제(객체가 없을 때만, 0·현재 레이어 제외), 색상, 켜기/끄기(눈), 잠금(자물쇠), 선종류(CONTINUOUS·CENTER·HIDDEN·PHANTOM) |
| ZOOM | Z | `E` 전체 보기, 또는 두 구석 지정(확대 창) |
| OPEN / QSAVE / SAVEAS / NEW | Ctrl+O / Ctrl+S | 파일 열기·저장·새 도면 |
| OPTIONS | OP | 설정 |
| HELP | ? | 명령어·단축키 표 |

## 6. 레이어 규칙
- **잠긴 레이어**의 객체는 선택·이동·삭제·자르기·속성 변경이 되지 않습니다(흐리게 표시, 스냅은 가능). 새 객체를 그리는 것은 가능합니다.
- **꺼진 레이어**의 객체는 보이지 않고 선택·스냅도 되지 않지만 도면 데이터와 저장 파일에는 그대로 남습니다.

## 7. DXF 파일
- **열기**: ASCII DXF(AutoCAD R12~최신 형식). 한글 도면(CP949·UTF-8)을 자동 판별합니다. DWG와 이진 DXF는 지원하지 않습니다(AutoCAD 등에서 ASCII DXF로 저장 후 여십시오).
- **편집 가능한 객체**: 선, 원, 호, 폴리선(LWPOLYLINE·2D POLYLINE, 호 세그먼트 포함), 문자(TEXT), 치수(선형·정렬·지름·반지름).
- **미지원 객체**(블록 참조 INSERT, MTEXT, SPLINE, ELLIPSE, HATCH, 각도 치수, 3D 객체 등): 열 때 종류별 개수를 알려 드리며 **원본 그대로 보존**합니다. 가능한 것은 화면에 표시(편집 불가)합니다.
- **저장**: AutoCAD R12 DXF. CAM·레이저 프로그램과의 호환성이 가장 넓은 형식입니다.
  - 원·호는 원래 형상 그대로, 폴리선의 호는 bulge 값으로 저장(선분으로 쪼개지 않음).
  - 치수가 있으면 "치수를 선·문자로 분해" 옵션을 고를 수 있습니다(CAM 전달용).
  - R12에 없는 객체(MTEXT·SPLINE·ELLIPSE 등)는 "근사 형상으로 변환하여 포함" 또는 "제외"를 고릅니다. 제외해도 열려 있는 도면에서는 보존됩니다.
  - 원본 파일을 묻지 않고 덮어쓰지 않습니다. 새 파일 이름으로 저장(내려받기)합니다. 같은 세션에서 "다른 이름으로 저장"한 파일은 이후 Ctrl+S로 같은 파일에 저장됩니다(지원 브라우저).
  - R12 형식에는 단위 정보가 없습니다. 받는 프로그램에서 mm로 지정하십시오.

## 8. 설정
- 오른쪽 위 ⚙ 버튼(1회 클릭): 테마, 그리드, 표시 소수 자리, 스냅 종류, 선택 상자·스냅 범위, 치수 소수 자리·문자 높이·화살표 크기, 기본 문자 높이, 동일 지름 허용오차, 자동 저장, 앱 공유(링크·QR코드), 버전 정보·업그레이드.
- **표시 소수 자리**는 화면 표시만 바꾸며 내부 좌표는 반올림하지 않습니다.

## 9. 관리자 설정 (숨김)
- 설정 창 머리의 ⚙ 아이콘을 **3초 안에 5번** 누르면(키보드: 아이콘에 초점을 두고 Enter 5번) 관리자 비밀번호 창이 나타납니다. 5번 누르기만으로는 들어갈 수 없습니다.
- 처음에는 이 기기 전용 비밀번호를 등록합니다(6자 이상). 비밀번호는 원문이 아닌 해시로만 저장되며 다른 기기와 동기화되지 않습니다.
- 5번 틀리면 5분간 잠깁니다. 인증 후 5분간 조작이 없으면 다시 인증해야 합니다.
- 관리자 기능: 성능 측정(1천/1만/5만 객체 시험 도면), 비밀번호 변경·재설정, 자동 저장 도면 삭제, 설정 초기화.

## 10. 공유·버전
- 공유: 앱 주소 링크 복사, 큰 QR코드 표시·이미지 저장. 도면·비밀번호·설정은 공유되지 않습니다. 로컬 주소(localhost)에서는 다른 기기에서 열 수 없다는 안내가 나옵니다.
- 버전: 상태 표시줄 오른쪽의 작은 "V0"를 누르면 버전·변경 내역·업그레이드 확인. 배포 주소에 새 버전이 있으면 안내하며, 자동 설치형 업데이트는 지원하지 않습니다.

## 11. 알려진 제한 (V0)
- DWG, 3D, 해치 편집, 블록 편집/분해, 연장(EXTEND)·모깎기(FILLET)·대칭(MIRROR)·배열 등은 아직 없습니다.
- 실제 AutoCAD 프로그램에서 저장 파일을 열어 보는 시험은 하지 못했습니다(독립 DXF 라이브러리 ezdxf 감사로 대신 검증).
- 문자 폭은 근사 계산이라 글꼴에 따라 선택 영역이 조금 다를 수 있습니다.
