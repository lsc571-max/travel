# 푸른 AI CAM V0.5 사용 방법

## 0. 실행
1. `pureun-ai-cam.html` 을 더블클릭한다.
   - 크롬이나 엣지를 권장한다.
   - 인터넷은 필요 없다.
2. 처음 열면 예제 프로젝트(M6·M5 탭 플레이트)가 나온다.
3. 새로 시작하려면 머리글의 **[프로젝트] → [+ 새 프로젝트]** 를 누른다.
4. 데이터는 이 PC 브라우저에 자동 저장된다. 다른 PC로 옮길 때는 **설정 → 전체 백업**을 쓴다.

## 1. 화면 구성
| 위치 | 내용 |
|---|---|
| 머리글 | 프로젝트 이름, 되돌리기/다시 하기, [프로젝트] [장비·공구] [작업지시서], 공유, 설정, **[NC 저장]** |
| 왼쪽 위 **작업 흐름** | ① 소재 → ② 원점·NC → ③ 가공 → ④ 확인 → ⑤ NC 저장. 단계마다 ✓(완료)·숫자(아직)·!(오류) 표시, 누르면 그 단계로 이동 |
| 왼쪽 **작업 목록** | ① 공통 정보(소재·고정, 원점·NC 출력) → ② 가공(위에서부터 순서대로) → [+ 구멍] [+ 탭] [+ 포켓] |
| 가운데 **화면** | [2D 배치] 위치 입력·순서 확인 / [3D 시뮬레이션] 가공 재생 |
| 오른쪽 **속성** | 왼쪽에서 고른 항목의 입력 칸 |
| 아래 **상태 표시줄** | 검증 결과(통과/경고/오류), 검증용(TEST) 표시, 예상 가공 시간, 공구·공정 수, [검증 결과] [G코드] 서랍 |

작업 목록 오른쪽의 아이콘은 그 항목의 상태를 나타낸다: ✔ 문제 없음 · ⚠ 경고 확인 · ✖ 오류(NC 저장 차단).

## 2. 기본 작업 순서
1. **소재·고정**: 재질, 크기(X·Y·두께), 원점 위치, 하부 여유, 클램프를 입력한다.
   - Z0 은 항상 소재 윗면이다.
2. **원점·NC 출력**: 좌표계(G54~), 프로그램 번호, 초기점 Z(안전 높이), 구멍 사이 이동 높이(G98/G99), 순서를 정한다.
   - 초기점과 R점은 다르다. 초기점은 이동용 안전 높이이고, R점은 절삭 이송을 시작하는 높이다.
3. **가공 추가**: [+ 구멍] / [+ 탭] / [+ 포켓] 중 하나를 누른다.
   - 공구·조건·사이클은 자동으로 정해진다.
4. **위치 입력**: 속성 패널 ② 위치에서 개별·직선·사각 배열·원형(PCD) 중 하나로 입력한다.
   - 2D 화면의 [위치 추가] 도구로 클릭해도 된다. 격자 스냅 5mm 가 기본이다.
5. **확인**: 깊이 단면도에서 Z값을 확인하고, [3D 시뮬레이션]으로 가공 과정을 본다.
6. **[NC 저장]**:
   - 오류가 있으면 저장이 막힌다(자물쇠 표시). 상태 표시줄의 빨간 항목을 누르면 고칠 곳으로 이동한다.
   - 저장 창에서 파일 이름을 정하고 **가공 전 점검 3항목**을 모두 체크해야 저장된다. 실가공 검증 전 장비는 파일 이름 앞에 `TEST_` 가 항상 붙는다.

## 3. 가공별 입력
### 구멍
- 지름과 깊이를 입력한다(또는 관통을 체크한다). 보유 드릴 버튼으로 바로 고를 수 있다.
- 공정은 센터 드릴 → 드릴로 구성된다.
- 드릴 사이클은 깊이/지름 비율로 자동 선택된다: G81 일반, G73 고속 펙, G83 심공.
- 깊이 기준은 "유효 깊이(직경부)" 또는 "드릴 끝" 중에서 고른다.

### 탭
- 나사 규격(M3~M20, 가는 나사 포함)과 탭 끝 깊이를 입력한다.
- 센터 → 기초 드릴(추천 지름) → 탭 순서로 구성된다.
- 리지드 탭을 지원하는 장비는 M29+G84 를 쓴다. 탭 이송 F 는 S × 피치로 자동 계산된다.
- 탭 가공 중에는 이송·주축 오버라이드를 100% 로 둔다.

### 포켓 (V0.4 신규, V0.5 확장)
> **V0.5 추가**
> - 모양: **사각 · 원형 · 다각(육각·오각…, 변 수·꼭짓점 지름 또는 맞변 거리·회전·모서리 R)** · 도면 형상.
> - **가공 단계**: ① 황삭 → ② 중삭(선택) → ③ 정삭. 위쪽 단계 상자에 남김 여유가 보인다.
>   - 중삭: [중삭 단 깊이] 0 = 한 번에(전체 높이), 0.5·1 = 그만큼씩 내려가며 측벽을 깎고 마지막 단에서 바닥까지. 중삭 측벽·바닥 남김을 따로 넣는다.
>   - 정삭: **바닥·측벽 따로**(바닥 정삭 → 측벽 정삭, 측벽은 단 깊이씩도 가능) 또는 **한 번에**.
>   - 예) 황삭 측벽 0.2 · 바닥 0.1 → 중삭 측벽 0.1 · 바닥 0.05 → 바닥 정삭 → 측벽 정삭.
> - **진입 방식**: 헬리컬(돌면서 천천히, 권장) · 램프(경로 따라 3°) · **선가공 구멍**(센터 → 드릴을 자동 추가하고 그 구멍으로 수직 진입. 드릴 끝은 황삭 바닥까지라 최종 바닥을 건드리지 않음).
> - **모서리 릴리프 구멍**(사각): 코너 R 이 공구보다 작을 때 네 모서리를 드릴로 뚫어 직각 모서리를 만든다 (벽 밖으로 조금 파고듦 — 도면 허용 확인).
> - **측벽 형상**: 구배(°, 입구가 도면 치수), 입구 R(윗 모서리), 바닥 R(아래 모서리)을 켜고 끌 수 있다. 평 엔드밀로 [계단 높이]씩 위에서부터 깎는 근사 가공이다. 2D 화면의 **[단면도]** 로 모양을 확인한다.
> - 2D 화면에서 포켓 위치를 고르면 **□ 손잡이**가 나온다. 끌면 크기가 바뀌고 공구·경로가 다시 계산된다.

1. 모양을 고른다: **사각(코너 R)** 또는 **원형**.
2. 크기와 깊이를 입력한다. 위치는 **포켓 중심**이다.
3. 공구는 "자동 선택(권장)"으로 두면 아래 규칙으로 정해진다.
   - 포켓 폭의 75% 이하인 가장 큰 평 엔드밀을 쓴다.
   - 코너 R 이 있으면 반경이 코너 R 이하인 공구를 우선한다.
4. 가공 과정은 다음과 같다.
   - **헬리컬 진입**: 포켓 중심에서 경사 3° 로 내려간다.
   - **황삭**: 안쪽에서 바깥쪽으로 반시계 방향(하향 절삭)으로 깎고, 측벽 0.2 · 바닥 0.1 mm 를 남긴다.
   - **정삭**: 최종 깊이에서 한 번 더 깎는다.
5. [절삭 설정]에서 다음 값을 바꿀 수 있다.
   - 경로 간격: 공구 지름의 %, 10~75, 권장 40~50
   - 1회 절입: 0 이면 재질·공구로 자동 계산
   - 측벽·바닥 남김 여유
6. 맞는 엔드밀이 없으면 **[공구 추가: 평 엔드밀 Ø…]** 버튼이 나온다. 공구가 생길 때까지 NC 저장은 막힌다.
7. 관통 포켓, 섬(안쪽 남김) 있는 포켓, 자유 곡선 포켓은 아직 지원하지 않는다.

### 직접 구성 (고급)
- 공정 카드를 직접 추가하고 순서를 바꾼다. 공정 묶음(프리셋)을 적용하거나 저장할 수 있다.
- 간편 입력 가공의 [공정 상세 편집]에서 값을 바꾸면 그 가공은 직접 구성으로 바뀐다.

### 윤곽 (V0.5 신규)
- [+ 윤곽]을 누르면 소재보다 사방 2mm 작은 사각 부품이 만들어진다. 측면 2mm 를 깎는 설정이다.
- 방향을 고른다.
  - **바깥 윤곽**: 부품 외곽을 따라 깎는다. 공구가 부품 바깥을 시계 방향으로 돌며, 하향 절삭이다.
  - **안쪽 윤곽**: 창이나 큰 구멍의 안쪽 벽을 반시계로 깎는다.
- 모양은 사각·원형·도면 형상 중에서 고르고, 크기와 깊이를 입력한다.
- 입력 항목:
  - **측면 제거 폭**: 부품 밖에 남은 소재 폭이다. 이 폭만큼 바깥 → 부품 쪽으로 여러 바퀴 돈다.
  - **관통(잘라내기)**: 깊이가 소재 두께 + 관통 여유가 된다. 관통 여유는 **하부 여유(패럴렐 틈) 이하**여야 한다.
    - 부품이 떨어질 수 있다. 탭(브리지) 기능은 아직 없다.
- 진입은 윤곽 밖(안쪽 윤곽이면 안)의 진입점에서 헬리컬로 내려가 직선으로 접근한다.

### 평면 (V0.5 신규)
- [+ 평면]을 누르면 소재 전체 윗면을 깎는다. 위치 입력은 없다.
- 공구는 페이스밀(T20 Ø50)이 기본이고, 없으면 엔드밀을 쓴다.
- 줄 간격(%)·1회 절입·가장자리 밖 여유를 입력한다.
- 공구는 항상 소재 밖에서 내려가고, 소재 밖에서 다음 줄로 옮긴다.
- ⚠ 평면 후 윗면은 Z-깊이가 된다. 다른 가공의 깊이는 **원래 윗면(Z0)** 기준이므로 평면 깊이를 더해 입력해야 한다.
- 소재 옆 클램프는 평면 가공 범위와 겹치면 차단된다. 바이스로 고정하는 것을 권장한다.

### 모따기 (V0.5 신규)
- [+ 모따기]를 누르면 기본으로 소재 바깥 모서리에 C0.5 를 만든다.
- 바깥 모서리 / 안쪽 모서리(포켓·구멍 입구) 중에서 고르고, 모양·크기·모따기 폭 C 를 입력한다.
- 공구는 90° 모따기 공구(T21)를 쓴다.
  - 공구 끝은 모따기 면보다 0.3mm 더 내려간다(끝 여유). 끝 마모를 막기 위해서다.
- **구멍 입구 모따기**: 모양 [원형], 지름 = 구멍 지름, [안쪽 모서리], 위치는 구멍과 같게 둔다.
- 모따기는 그 면을 먼저 깎은 뒤에 해야 한다(목록 아래쪽). 깎이지 않은 소재로 내려가면 검증기가 차단한다.

### 자유 형상 포켓 (V0.5 신규)
- 도면(DXF)에서 가져온 닫힌 선을 포켓으로 쓸 수 있다. 안에 있는 닫힌 선은 **섬**(깎지 않고 남길 부분)이 된다.
- 경로: 안쪽에서 바깥으로 오프셋하며 깎는다. 남는 살이 없도록 경로 간격은 공구 반경의 95% 이하로 자동 제한된다.
- 진입: 공간이 있으면 헬리컬로, 좁으면 윤곽을 따라 3° 경사로 내려간다.
- [관통]을 체크하면 끝까지 뚫는다. 사각·원형 포켓도 같다.

## 4. 도면(DXF) 불러오기 (V0.5 신규)
1. 작업 목록 아래 **[도면(DXF) 불러오기]** 를 누르고 DXF 파일을 고른다(ASCII DXF).
   - CAD 에서 "DXF 로 저장"하면 된다.
   - 스플라인은 폴리선으로, 블록은 분해(EXPLODE)해서 저장한다.
2. 미리보기와 표에서 확인하고 고친다.
   - **원**: 지름별로 묶인다.
     - 지름이 나사 기초 드릴과 같으면 **탭** 을 추천한다(예: Ø6.8 → M8).
     - 큰 원(Ø20 초과)은 원형 포켓을 추천한다.
   - **닫힌 윤곽**: 가장 바깥은 **바깥 윤곽**, 그 안은 **포켓**, 포켓 안은 **섬** 으로 자동 분류한다. 바꿀 수 있다.
   - 가공별 **깊이** 를 입력한다.
   - "소재 크기를 도면 범위 + 여유로 맞추고 원점을 왼쪽 아래로"를 켜 두면 소재와 원점이 자동으로 정해진다(기본 여유 2mm).
3. **[가공 만들기]** 를 누르면 구멍·탭 → 포켓 → 바깥 윤곽(마지막) 순서로 가공이 만들어진다.
4. 각 가공의 깊이·공구·관통 여부를 확인한다. 예제는 `examples/샘플_브라켓.dxf` 이다.
- 단위는 도면 헤더($INSUNITS)를 따른다: inch·cm·m 는 mm 로 바꾸고, 없으면 mm 로 읽는다.
- 끝점이 0.01mm 이상 떨어진 열린 선은 제외하고 알려 준다.

| 복제 | **Ctrl+D**, 또는 항목에 마우스를 올리면 나오는 복제 아이콘 |

| 이름 바꾸기 | **F2** |
| 순서 바꾸기 | **Alt+↑ / Alt+↓**, 또는 항목을 **끌어서 놓기** |

## 6. 화면 크기 조절 (V0.5 신규)
- 왼쪽 목록 | 가운데 화면 | 오른쪽 속성 | 아래 서랍 사이 **경계선을 끌면** 크기가 바뀐다.
  - 경계에 마우스를 올리면 파란 선이 보인다.
  - **더블클릭** 하면 기본 크기로 돌아간다.
  - 키보드로는 경계에 초점을 두고 ←/→(↑/↓) 를 누른다. Shift 를 함께 누르면 크게 움직인다.
- 화면 위쪽 오른편의 두 아이콘으로 왼쪽 목록·오른쪽 속성을 **숨기거나 보이게** 할 수 있다. 숨기면 2D·3D 화면이 넓어진다.
- 조절한 크기는 기억되어 다음에 열어도 유지된다.

## 6-1. 화면 배치 바꾸기 (V0.5 신규)
- **머리글 아이콘**(되돌리기·프로젝트·장비·작업지시서·공유·테마·설정)은 **끌어서** 원하는 순서·묶음으로 옮긴다.
- **2D 배치 / 3D 시뮬레이션** 탭과 아래 서랍의 **검증 결과 / G코드** 탭도 끌어서 순서를 바꾼다.
- 화면 위 오른쪽 **⇄ 아이콘**: 작업 목록과 속성 패널의 **자리를 바꾼다** (목록을 오른쪽에 두고 싶을 때).
- 바꾼 배치는 기억된다. [설정] → **화면 배치 초기화** 로 처음대로 돌린다.

## 6-2. 이미 가공된 형상 인식 (V0.5 신규, 깊이 기준 '자동')
- [원점·NC 출력] → **깊이 기준**: "먼저 가공된 바닥 기준 (자동)"이 새 프로젝트의 기본이다. 이전 버전 파일은 "Z0 기준"으로 열린다.
- 자동이면:
  - 포켓(깊이 10) 안에 구멍(깊이 8)을 넣으면 **포켓 바닥에서 8** 을 더 내려가 실제 끝은 Z−18 이 된다 (도면 치수 방식).
  - 포켓 안 포켓, 평면 가공 뒤의 포켓·구멍도 같은 방식이다.
  - 앞 공정이 이미 깎은 곳은 그 높이에서 R점·진입을 시작한다 (빈 공간을 천천히 내려가지 않음).
  - 속성 패널의 **먼저 가공된 바닥 기준** 상자에 기준면·시작면·실제 끝 Z 가 나온다.
- 탭·드릴이 포켓 바닥에서 시작하면 고정 사이클은 안전을 위해 **G98(초기점 복귀)** 로 나온다.

## 7. Z값 확인
- **깊이 단면도**(속성 패널): 초기점 Z, R점, Z0 소재 윗면, 공정별 공구 끝 Z, 포켓 단(절입)별 Z, 소재 밑면을 한 그림에 보여 준다. 크기는 축척이 아니다.
- **2D 화면**: 구멍·포켓 아래에 바닥 Z 가 표시된다. 마우스를 올리면 커서 위치의 X·Y 와 그 가공의 바닥 Z 가 나온다.
- **위치 표**: 각 위치의 바닥 Z 열이 있다.
- **3D 시뮬레이션**: 왼쪽 위 정보 상자에 현재 공구 위치 X·Y·Z 가 표시되고, 마우스를 올린 소재 표면의 X·Y·Z 도 나온다.

## 8. 3D 시뮬레이션
- 조작:
  - 마우스: 왼쪽 드래그는 회전, 오른쪽(또는 Shift) 드래그는 이동, 휠은 확대.
  - 터치: 한 손가락은 회전, 두 손가락은 확대·이동.
  - 보기 버튼: [등각] [위] [앞] [옆].
- 재생 막대:
  - 버튼: 재생/일시정지(Space), 이전·다음 공구, 가공 완료 상태로.
  - 속도: 1~100배.
  - 타임라인을 끌면 원하는 시점으로 이동한다. 색 띠는 공구 종류를 뜻한다: 센터 초록, 드릴 파랑, 탭 보라, 엔드밀 주황.
- **G코드 서랍에서 줄을 누르면** 시뮬레이션이 그 줄 위치로 이동한다.
- [공구 경로]를 켜면 경로가 함께 보인다: 급속은 주황, 절삭은 초록.
- [해상도]는 낮음·보통·높음 중에서 고른다. 높을수록 정밀하지만 느리다.
- **[단면 보기]**: 선택한 가공의 위치에서 앞쪽을 잘라, 구멍·탭·포켓의 깊이를 옆에서 볼 수 있다. [앞] 보기와 함께 쓰면 좋다.
- 깊이 표현: 깊이 깎인 곳일수록 어둡게 칠해진다.
- 알아 둘 점 (화면에도 표시됨):
  - 실제 NC 해석 결과로 소재를 깎는 **높이맵 근사** 시뮬레이션이다.
  - 홀더 간섭, 가감속, 탭 나사산 모양은 반영하지 않는다.
  - 3D 화면이 안 나오는 PC(WebGL 미지원)에서는 2D 화면과 검증만 쓸 수 있다.

## 9. 검증 결과·G코드 (아래 서랍)
- 상태 표시줄의 [검증 결과] 또는 [G코드]를 누르면 서랍이 열린다.
- **확인할 내용**을 누르면 해당 가공이나 G코드 줄로 이동한다.
- **G코드 직접 수정**: 수정하는 순간 기존 검증이 무효가 된다. [수정본 재검증]을 통과해야 저장·복사할 수 있다. 수정본은 `_EDIT` 파일명과 `(USER EDITED…)` 주석이 붙는다.

## 10. 작업지시서 (셋업시트)
- 머리글의 **[작업지시서]**를 누르면 미리보기가 열리고, [인쇄]를 누르면 A4 로 인쇄된다(PDF 저장 가능).
- 담는 내용:
  - 장비·소재·원점·초기점·클램프
  - 예상 시간
  - 공구표(공구별 시간과 확인란)
  - 가공 순서(공구 끝 Z·S·F)
  - 확인 사항과 가공 전 점검
  - 서명란

## 11. 장비·공구
- 머리글 **[장비·공구]**에서 장비(행정·회전수·이송·리지드 탭·헬리컬 지원·급속 이송·공구 교환 시간)와 공구 목록을 관리한다.
- 공구 종류는 드릴·센터·탭·평 엔드밀·**페이스밀·모따기 공구**이다. 모따기 공구는 각도(90°)와 끝 평면 지름을 입력한다. 엔드밀은 날 수, 날 길이(가공 가능 최대 깊이), 재질을 입력한다.
- 장비 설정을 바꾸면 실가공 검증 승인이 자동으로 해제된다.
- 예상 가공 시간은 급속 이송과 공구 교환 시간 값으로 계산한 **추정치**다(가감속 미반영).

## 12. 설정·관리자·공유
- **[설정]**(톱니): 테마(밝게/어둡게), 글자 크기, 경고음, 공유·QR, 버전 정보, 전체 백업·복원.
- 관리자 설정은 숨겨져 있다. 설정 창 제목 옆 톱니를 **3초 안에 5번** 누르고 비밀번호로 인증해야 열린다.
  - 장비 실가공 검증 승인을 하면 TEST 표시가 해제된다.
  - 비밀번호 변경과 데이터 초기화도 여기서 한다.
- 공유: 웹에 배포된 주소에서 열면 링크와 QR코드가 나온다. 로컬 파일로 실행 중이면 HTML 파일 자체를 전달한다.
