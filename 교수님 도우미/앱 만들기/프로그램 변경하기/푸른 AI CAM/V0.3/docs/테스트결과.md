## 2. 모듈화 전후 비교 (기존 기능 유지 확인)
- 같은 무작위 입력 1,200건 (정상 800 + 비정상 400)을 V0.1 단일 엔진과 V0.2 모듈 엔진에 넣어 비교했다.
- 비교 항목: 검증 결과(문제 목록 전체), 공정 계획(순서·병합·구멍 순서), G코드 텍스트, 구멍 목록, 교차 검증 일치 여부.
- 계산값 비교: 공구 13개 × 가공 6종 × 재질 7종 × 깊이 방식 4가지의 깊이·조건·추천값, 기초 드릴 표, 배열 좌표, 기본 공정 묶음.
- **1단계(모듈 분리만):** 1,200건 모두 완전히 같았다 (G코드 생성 802건 한 글자까지 동일).
- **2단계(안전 수정 후):** 아래의 의도한 변경 말고는 차이가 없다. 의도한 변경은 테스트 안에 목록으로 명시해 두었다.
  - G코드 안전 블록에 `G94` 추가
  - 주축이 회전 중일 때 `M29` 앞에 `M05` 추가 (무작위 1,200건 중 해당 0건, 별도 테스트로 확인)
  - 소재 범위·클램프를 가장 큰 공구 반경으로 검사 (V0.1 보다 엄격해질 수만 있음; 무작위 1,200건 중 0건)

## 3. 독립 검증 결과와 조치
개발 AI 와 분리된 검증 AI 가 코드만 받아 직접 실행해 결함을 재현했다. 모든 항목은 `tests/safety-v02.test.cjs` 에서 "수정 전에는 통과하던 위험 NC 가 이제 차단되는지"로 다시 확인한다.

### 1차 (V0.1 대상) — 9건 모두 수정
| 등급 | 내용 | 조치 |
|---|---|---|
| 중대 | 소재를 관통하는 급속 이동 미탐지 | 이동 선분 전체 검사 |
| 중대 | 수정 NC 재검증 후 소재 변경 시 옛 결과로 다운로드 | 매 재계산마다 현재 조건으로 재검사 |
| 주요 | 수정 NC 의 탭 기초 구멍·깊이, 비정상 절삭 조건 미검사 | 위치별 드릴 기록, Vc·회전당 이송 한계 |
| 주요 | 좌표계 누락·변경 미검사 | 오류 |
| 주요 | 소재 높이 G01 측면 이동 경고만 | 오류 |
| 주요 | G94 미출력 | 출력 + G94 전 F 사용 오류 |
| 경미 | 회전 중 M29 | M05 출력 + 오류 |
| 경미 | N 번호 5자리 초과 | 5자리 이내 + 오류 |
| 경미 | 차단 중 복사 가능 | 복사 차단 |

### 2차 (V0.2 대상) — 확인된 우회 6건 + 불일치 1건 + 경미 3건 모두 수정

### 생성 NC 일관성
- 검증 AI: 무작위 3,000건 중 모델 오류 0인 1,196건 모두 검증기 오류 0, 교차 검증 일치.
- 자체 테스트: 무작위 2,000건 (원점 5종, G98/G99, G54/G55/G59, 클램프, 시퀀스 번호, 리지드 탭 M03 옵션, 일반/리지드 탭 혼용) — 모델 오류 0 이면 검증기 오류 0·일치 (수정 후 재실행 통과).
- 4,590홀·시퀀스 번호 프로젝트: N ≤ 99999, 오류 0, 2초 이내.
