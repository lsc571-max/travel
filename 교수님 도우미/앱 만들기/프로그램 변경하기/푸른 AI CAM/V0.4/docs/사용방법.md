# 푸른 AI CAM V0.4 사용 방법

## 0. 실행
1. `pureun-ai-cam.html` 을 더블클릭한다.
   - 크롬이나 엣지를 권장한다.
   - 인터넷은 필요 없다.
2. 처음 열면 예제 프로젝트(M6·M5 탭 플레이트)가 나온다.
3. 새로 시작하려면 머리글의 **[프로젝트] → [+ 새 프로젝트]** 를 누른다.
4. 데이터는 이 PC 브라우저에 자동 저장된다. 다른 PC로 옮길 때는 **설정 → 전체 백업**을 쓴다.

## 1. 화면 구성
| 위치 | 내용 |
|---|---|
| 머리글 | 프로젝트 이름, 되돌리기/다시 하기, [프로젝트] [장비·공구] [작업지시서], 공유, 설정, **[NC 저장]** |
| 왼쪽 **작업 목록** | ① 공통 정보(소재·고정, 원점·NC 출력) → ② 가공(위에서부터 순서대로) → [+ 구멍] [+ 탭] [+ 포켓] |
| 가운데 **화면** | [2D 배치] 위치 입력·순서 확인 / [3D 시뮬레이션] 가공 재생 |
| 오른쪽 **속성** | 왼쪽에서 고른 항목의 입력 칸 |
| 아래 **상태 표시줄** | 검증 결과(통과/경고/오류), 검증용(TEST) 표시, 예상 가공 시간, 공구·공정 수, [검증 결과] [G코드] 서랍 |

작업 목록 오른쪽의 아이콘은 그 항목의 상태를 나타낸다: ✔ 문제 없음 · ⚠ 경고 확인 · ✖ 오류(NC 저장 차단).

## 2. 기본 작업 순서
1. **소재·고정**: 재질, 크기(X·Y·두께), 원점 위치, 하부 여유, 클램프를 입력한다.
   - Z0 은 항상 소재 윗면이다.
2. **원점·NC 출력**: 좌표계(G54~), 프로그램 번호, 초기점 Z(안전 높이), 구멍 사이 이동 높이(G98/G99), 순서를 정한다.
   - 초기점과 R점은 다르다. 초기점은 이동용 안전 높이이고, R점은 절삭 이송을 시작하는 높이다.
3. **가공 추가**: [+ 구멍] / [+ 탭] / [+ 포켓] 중 하나를 누른다.
   - 공구·조건·사이클은 자동으로 정해진다.
4. **위치 입력**: 속성 패널 ② 위치에서 개별·직선·사각 배열·원형(PCD) 중 하나로 입력한다.
   - 2D 화면의 [위치 추가] 도구로 클릭해도 된다. 격자 스냅 5mm 가 기본이다.
5. **확인**: 깊이 단면도에서 Z값을 확인하고, [3D 시뮬레이션]으로 가공 과정을 본다.
6. **[NC 저장]**: 오류가 있으면 저장이 막히고, 상태 표시줄의 빨간 항목을 누르면 고칠 곳으로 이동한다.

## 3. 가공별 입력
### 구멍
- 지름과 깊이를 입력한다(또는 관통을 체크한다). 보유 드릴 버튼으로 바로 고를 수 있다.
- 공정은 센터 드릴 → 드릴로 구성된다.
- 드릴 사이클은 깊이/지름 비율로 자동 선택된다: G81 일반, G73 고속 펙, G83 심공.
- 깊이 기준은 "유효 깊이(직경부)" 또는 "드릴 끝" 중에서 고른다.

### 탭
- 나사 규격(M3~M20, 가는 나사 포함)과 탭 끝 깊이를 입력한다.
- 센터 → 기초 드릴(추천 지름) → 탭 순서로 구성된다.
- 리지드 탭을 지원하는 장비는 M29+G84 를 쓴다. 탭 이송 F 는 S × 피치로 자동 계산된다.
- 탭 가공 중에는 이송·주축 오버라이드를 100% 로 둔다.

### 포켓 (V0.4 신규)
1. 모양을 고른다: **사각(코너 R)** 또는 **원형**.
2. 크기와 깊이를 입력한다. 위치는 **포켓 중심**이다.
3. 공구는 "자동 선택(권장)"으로 두면 아래 규칙으로 정해진다.
   - 포켓 폭의 75% 이하인 가장 큰 평 엔드밀을 쓴다.
   - 코너 R 이 있으면 반경이 코너 R 이하인 공구를 우선한다.
4. 가공 과정은 다음과 같다.
   - **헬리컬 진입**: 포켓 중심에서 경사 3° 로 내려간다.
   - **황삭**: 안쪽에서 바깥쪽으로 반시계 방향(하향 절삭)으로 깎고, 측벽 0.2 · 바닥 0.1 mm 를 남긴다.
   - **정삭**: 최종 깊이에서 한 번 더 깎는다.
5. [절삭 설정]에서 다음 값을 바꿀 수 있다.
   - 경로 간격: 공구 지름의 %, 10~75, 권장 40~50
   - 1회 절입: 0 이면 재질·공구로 자동 계산
   - 측벽·바닥 남김 여유
6. 맞는 엔드밀이 없으면 **[공구 추가: 평 엔드밀 Ø…]** 버튼이 나온다. 공구가 생길 때까지 NC 저장은 막힌다.
7. 관통 포켓, 섬(안쪽 남김) 있는 포켓, 자유 곡선 포켓은 아직 지원하지 않는다.

### 직접 구성 (고급)
- 공정 카드를 직접 추가하고 순서를 바꾼다. 공정 묶음(프리셋)을 적용하거나 저장할 수 있다.
- 간편 입력 가공의 [공정 상세 편집]에서 값을 바꾸면 그 가공은 직접 구성으로 바뀐다.

## 4. Z값 확인
- **깊이 단면도**(속성 패널): 초기점 Z, R점, Z0 소재 윗면, 공정별 공구 끝 Z, 포켓 단(절입)별 Z, 소재 밑면을 한 그림에 보여 준다. 크기는 축척이 아니다.
- **2D 화면**: 구멍·포켓 아래에 바닥 Z 가 표시된다. 마우스를 올리면 커서 위치의 X·Y 와 그 가공의 바닥 Z 가 나온다.
- **위치 표**: 각 위치의 바닥 Z 열이 있다.
- **3D 시뮬레이션**: 왼쪽 위 정보 상자에 현재 공구 위치 X·Y·Z 가 표시되고, 마우스를 올린 소재 표면의 X·Y·Z 도 나온다.

## 5. 3D 시뮬레이션
- 조작:
  - 마우스: 왼쪽 드래그는 회전, 오른쪽(또는 Shift) 드래그는 이동, 휠은 확대.
  - 터치: 한 손가락은 회전, 두 손가락은 확대·이동.
  - 보기 버튼: [등각] [위] [앞] [옆].
- 재생 막대:
  - 버튼: 재생/일시정지(Space), 이전·다음 공구, 가공 완료 상태로.
  - 속도: 1~100배.
  - 타임라인을 끌면 원하는 시점으로 이동한다. 색 띠는 공구 종류를 뜻한다: 센터 초록, 드릴 파랑, 탭 보라, 엔드밀 주황.
- **G코드 서랍에서 줄을 누르면** 시뮬레이션이 그 줄 위치로 이동한다.
- [공구 경로]를 켜면 경로가 함께 보인다: 급속은 주황, 절삭은 초록.
- [해상도]는 낮음·보통·높음 중에서 고른다. 높을수록 정밀하지만 느리다.
- 알아 둘 점 (화면에도 표시됨):
  - 실제 NC 해석 결과로 소재를 깎는 **높이맵 근사** 시뮬레이션이다.
  - 홀더 간섭, 가감속, 탭 나사산 모양은 반영하지 않는다.
  - 3D 화면이 안 나오는 PC(WebGL 미지원)에서는 2D 화면과 검증만 쓸 수 있다.

## 6. 검증 결과·G코드 (아래 서랍)
- 상태 표시줄의 [검증 결과] 또는 [G코드]를 누르면 서랍이 열린다.
- **확인할 내용**을 누르면 해당 가공이나 G코드 줄로 이동한다.
- **G코드 직접 수정**: 수정하는 순간 기존 검증이 무효가 된다. [수정본 재검증]을 통과해야 저장·복사할 수 있다. 수정본은 `_EDIT` 파일명과 `(USER EDITED…)` 주석이 붙는다.

## 7. 작업지시서 (셋업시트)
- 머리글의 **[작업지시서]**를 누르면 미리보기가 열리고, [인쇄]를 누르면 A4 로 인쇄된다(PDF 저장 가능).
- 담는 내용:
  - 장비·소재·원점·초기점·클램프
  - 예상 시간
  - 공구표(공구별 시간과 확인란)
  - 가공 순서(공구 끝 Z·S·F)
  - 확인 사항과 가공 전 점검
  - 서명란

## 8. 장비·공구
- 머리글 **[장비·공구]**에서 장비(행정·회전수·이송·리지드 탭·헬리컬 지원·급속 이송·공구 교환 시간)와 공구 목록을 관리한다.
- 공구 종류는 드릴·센터·탭·평 엔드밀이다. 엔드밀은 날 수, 날 길이(가공 가능 최대 깊이), 재질을 입력한다.
- 장비 설정을 바꾸면 실가공 검증 승인이 자동으로 해제된다.
- 예상 가공 시간은 급속 이송과 공구 교환 시간 값으로 계산한 **추정치**다(가감속 미반영).

## 9. 설정·관리자·공유
- **[설정]**(톱니): 테마(밝게/어둡게), 글자 크기, 경고음, 공유·QR, 버전 정보, 전체 백업·복원.
- 관리자 설정은 숨겨져 있다. 설정 창 제목 옆 톱니를 **3초 안에 5번** 누르고 비밀번호로 인증해야 열린다.
  - 장비 실가공 검증 승인을 하면 TEST 표시가 해제된다.
  - 비밀번호 변경과 데이터 초기화도 여기서 한다.
- 공유: 웹에 배포된 주소에서 열면 링크와 QR코드가 나온다. 로컬 파일로 실행 중이면 HTML 파일 자체를 전달한다.

## 10. 단축키
| 키 | 기능 |
|---|---|
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 하기 |
| Delete | 2D 화면에서 선택한 위치 삭제 |
| Esc | 2D 도구를 [선택]으로 |
| Space | 3D 시뮬레이션 재생/일시정지 |
| Alt+Shift+A | 관리자 인증 창 (접근성용, 비밀번호 필요) |
