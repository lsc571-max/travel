## 5. G코드 생성 (FANUC 포스트프로세서)
출력 구조: `%` → `O번호` → 정보 주석(버전·장비·재질·원점·공구 목록·TEST 표시) → `G21` → `G00 G17 G40 G49 G80 G90 G94` → `G91 G28 Z0.` → (공구별) `T__ M06` / `G00 G90 G54 X Y S M03` / `G43 Z초기점 H__ M08` / 고정 사이클 / `G80` / `M09 M05 G91 G28 Z0. G90 M01` → 종료 `G91 G28 Z0.` `G91 G28 Y0.` `G90` `M30` `%`.
- 모든 좌표·R·Q 에 소수점 강제 (FANUC 소수점 생략 시 1/1000 해석 방지)
- 주석은 ASCII 대문자만 (한글 등 제거)
- 공구 교환 최소화 + 같은 조건의 여러 그룹 병합, 그룹 내부 순서 보존 검사
- 같은 공구 연속 공정은 초기점 상승 후 XY 이동
- 리지드 탭 전 주축이 회전 중이면 M05 후 `M29 S__` (장비 옵션 'M03 출력' 제외)
- 시퀀스 번호는 N99999 이내 (블록이 많으면 1 간격, 그래도 넘으면 1부터 반복)
- 제어기별 포스트프로세서 등록 구조 (FANUC 지원, 미쓰비시·지멘스 개발 예정 — 선택 시 출력 차단)
- 화면 표시·복사·직접 수정·재검증·다운로드(CRLF)

## 6. 안전성 검증과 차단
### 6-1. 모델 검증 11개 항목 (입력값 기준)
1. 좌표값 유효성 (숫자, FANUC 입력 한계, 장비 행정)
2. 소재 범위 (홀 이탈 = 오류, 가장자리 살 두께 = 경고)
3. 중복·간섭 홀 (같은 위치 = 오류, 겹침 = 경고)
4. 공구 번호·종류 (미등록, 매거진 초과, 종류 불일치, 번호 중복)
5. 공구 직경·탭 기초 드릴 (기초 드릴 누락·과소·과대 = 오류, 추천값과 차이 = 경고)
6. 절삭 조건 (S·F 0 이하·장비 한계 초과, Vc 3배·이송 3배 초과 = 오류)
7. 탭 이송·장비 지원 (리지드 탭 미지원, 탭 최대 회전수, 비표준 피치)
8. 가공 깊이 (0 이하, 날장 초과, 하부 여유 초과, 탭이 드릴보다 깊음, 스팟 직경 초과)
9. 펙·사이클 조건 (Q 0.1 미만, 드웰 범위, 깊이/직경 비)
10. 안전 높이·충돌 (R점, 초기점, 클램프 겹침, 초기점 < 클램프, G99 경로 클램프 통과)
11. NC 구조·장비 설정 (프로그램 번호, 가공 내용 없음, 장비 미검증)

### 6-2. 독립 NC 해석 검증기
생성기와 별도의 코드로 NC 텍스트를 한 줄씩 해석하며 모달 상태(G90/G91, G98/G99, 사이클, 주축, 공구, G43)를 추적합니다.
- 문법: 지원 코드 목록 외 G/M 차단, 소수점 누락, 중복 주소, 괄호, 프로그램 번호, G21/M30/G80, G94 전 F 사용, N 5자리 초과, 좌표계 누락·변경
- 경로: 소재 범위, 바닥 아래, R점·초기점, G00 소재 진입, **이동 선분 전체의 소재 통과(G00·G01)**, 클램프 충돌, G90 상태 G28
- 조건: 탭 F = S × P, M29 S, 주축 회전 중 M29, 주축 정지 상태 가공, H ≠ T, 공구 종류와 사이클 불일치, S·F 장비 한계, **Vc·회전당 이송 3배 초과**
- 공정(수정 NC 포함): **탭 위치마다 앞서 가공된 적합 직경 기초 구멍과 깊이 확인** (좌표계별)
- 모달 해석: 같은 그룹 G코드 동시 지령 차단, G00/G01 과 사이클 동시 차단, G00·G01 후 리지드 탭 모드 해제, M06 후 주축 정지로 간주, 소재 아래 G01 차단, XY 미지정 상태 Z 하강 차단
- 교차 검증: 생성기가 계산한 구멍(공구·X·Y·Z·R·사이클)과 해석 결과가 100% 일치해야 통과

### 6-3. 차단 규칙
- 모델 오류 1건 이상, 또는 NC 해석 오류 1건 이상 → **NC 다운로드 차단** (경고음·안내)
- 직접 수정한 G코드 → 기존 검증 무효, 재검증 통과 전 차단, 수정 시마다 재검증 필요. 재검증 후 소재·장비·클램프가 바뀌면 현재 조건으로 자동 재검사
- 검증을 통과하지 못한 G코드는 복사 버튼도 차단
- 실가공 미검증 장비 → `TEST_` 파일명 + `(*** TEST ONLY - MACHINE NOT VERIFIED ***)` 주석
- 원격 가동 기능 없음 (작업자가 장비 앞에서 직접 확인 후 가동)
