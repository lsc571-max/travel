# 라이선스·외부 구성 요소

## 포함된 외부 라이브러리 (실행 파일에 포함)
| 이름 | 버전 | 용도 | 라이선스 | 상업적 사용·배포 |
|---|---|---|---|---|
| qrcode-generator (Kazuhiko Arase) | 1.4.4 | 공유 QR코드 생성 | MIT | 가능. 저작권·허가 고지를 함께 배포해야 한다. 빌드할 때 HTML 안에 전문이 자동 포함된다 (`src/vendor/LICENSE-qrcode-generator.txt`) |
| three.js (three.js authors) | 0.149.0 (r149) | 3D 가공 시뮬레이션 화면 (WebGL) | MIT | 가능. 저작권·허가 고지를 함께 배포해야 한다. 빌드할 때 HTML 안에 전문이 자동 포함된다 (`src/vendor/LICENSE-three.txt`, 원본 `build/three.min.js`) |

"QR Code"는 DENSO WAVE INCORPORATED 의 등록 상표입니다.

## 참고만 한 오픈소스 (코드·문구 미사용)
FreeCAD CAM(LGPL), Kiri:Moto(MIT), jsCut(GPL-3), bCNC(GPL-2), CAMotics(GPL-2) 의 소스와 문서를 **읽고 개념만 참고**했다 (→ [오픈소스CAM_참고분석.md](오픈소스CAM_참고분석.md)).
- 포켓 경로, 높이맵 시뮬레이션, 화면 코드는 모두 새로 작성했다.
- GPL 코드를 섞지 않았으므로 푸른 AI CAM 의 라이선스 선택에 제약이 없다.

## 푸른 AI CAM 자체 라이선스
아직 정하지 않았다. 협력업체 무료 제공과 향후 판매 조건이 정해지면 별도 라이선스(사용 허락 계약 또는 상용 EULA)를 작성해야 한다.
