# 푸른 AI CAM V0.5

소규모 기계가공 업체용 **FANUC 3축 머시닝센터 2.5축 CAM**. 설치 없는 단일 HTML 웹앱으로, 오프라인에서 동작하고 서버·AI API 비용이 없다.

V0.5 는 V0.4 를 바탕으로 한 **프로그램 변경** 버전이다. 2.5축 가공의 기본 종류를 모두 갖췄다.

| 가공 | 내용 |
|---|---|
| 구멍·탭 | 센터 → 드릴(사이클 자동) → 탭(리지드/일반) |
| 포켓 | 사각(코너 R)·원형·**다각**·**도면 자유 형상(섬 포함)**, **관통**, 헬리컬/램프/선가공 구멍 진입, 황삭·**중삭**·바닥/측벽 정삭, **구배·입구 R·바닥 R** |
| **윤곽** (신규) | 바깥(부품 외곽)·안쪽(창), 측면 여러 바퀴, 관통 절단, 하향 절삭 |
| **평면** (신규) | 페이스밀 지그재그, 소재 밖에서 진입 |
| **모따기** (신규) | 바깥·안쪽·구멍 입구 C 모따기 |
| **도면(DXF) 불러오기** (신규) | 원 → 지름별 구멍·탭, 닫힌 선 → 외곽·포켓·섬 자동 분류 |

**V0.5 2차 (사용자 추가 요청)**
- **이미 가공된 형상 인식**: 포켓 안 구멍·포켓 안 포켓·평면 뒤 가공은 그 바닥에서부터 깊이를 재고, 깎인 높이에서 시작한다.
- 포켓 **중삭**(한 번에 / 단 깊이씩), **바닥 정삭·측벽 정삭** 분리와 각각의 남김 여유.
- 포켓 **진입**: 헬리컬 · 램프 · 선가공 구멍(드릴 자동 추가), **모서리 릴리프 구멍**.
- **다각(정다각형)** 형상, **구배·입구 R·바닥 R** 측벽 형상(계단 근사, 검증기 판정).
- 2D **크기 손잡이**·**단면도**, 머리글 아이콘·탭 **끌어서 옮기기**, 좌우 **패널 자리 바꾸기**, 작업 순서 **다음 할 일** 안내.
- 독립 안전 검토 지적 사항 반영 (사실상 수직 하강 차단, 모따기 공구 오용 검출, 검증기 고속화, NC 줄 수 감소, DXF 보강).

화면도 편하게 바꿨다.
- **패널 크기 조절**: 경계를 끌어서 조절하고, 접을 수 있으며, 크기를 기억한다.
- **작업 목록에서 바로 편집**: Ctrl+C/V/D, Delete, F2, Alt+↑↓, 오른쪽 버튼 메뉴, 끌어서 순서 바꾸기.
- **삭제 후 [되돌리기]** 를 지원한다.

## 개발자용 명령 (Node.js 18 이상)
```bash
node build.mjs                     # src/ 를 pureun-ai-cam.html 로 통합 (three.js·Clipper·QR 포함, 약 1.3MB)
node --test tests/*.test.cjs       # 엔진 단위 + 전후 비교(V0.1~V0.4) + 포켓·V0.5 무작위 시험
node tests/e2e.cjs [스크린샷폴더]   # 브라우저 통합 테스트 (Playwright 필요)
```
