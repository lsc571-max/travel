| V0.2 | 2026-11-27 | `V0.2/` | 모듈 구조 + 안전 결함 수정 — 자동 테스트 통과, **실장비 미검증** |

## V0.2 (2026-11-27)
- **기준**: V0.1 폴더 전체를 복사해 시작 (V0.1 은 변경하지 않음, 검증 보고서 `V0.1/docs/테스트결과.md` 만 추가).
- **변경 사항**: 기능별 모듈 구조(공통 엔진·가공 모듈 6종·공정 관리·포스트프로세서·검증·저장·그래픽), 가공 모듈/제어기 등록소, 개발 예정 가공 4종·제어기 2종 표시. 독립 검증 2회의 결함(1차 9건, 2차 10건) 수정. 미지원 가공은 다른 가공으로 바꾸지 않고 제외.
- **검증 결과**: `V0.2/docs/테스트결과.md` — 엔진 82개·브라우저 63개 통과, 모듈화 전후 1,200건 비교 동일(의도한 변경만 차이).
- **복원 기준**: `V0.2/pureun-ai-cam.html` 단일 파일로 실행. 소스는 `V0.2/src/` + `node build.mjs`. V0.1 로 되돌리려면 `V0.1/pureun-ai-cam.html` 사용 (저장 데이터 형식 동일, schema 1).

## V0.1 (2026-11-27)
- **기준**: 신규 프로젝트 최초 버전 (기존 원본 없음). 사용자 지시문에 명시된 버전명 "V0.1" 사용.
- **변경 사항**: 최초 개발 — FANUC 3축 2.5축 홀 가공(G81·G82·G73·G83·G84·M29 리지드 탭), 홀 배열(개별·직선·사각·PCD), 공정 묶음, 장비·공구 관리, 11개 항목 모델 검증 + 독립 NC 해석 검증, 오류 시 NC 생성 차단, 로컬 저장·JSON 백업/복원, 공유·QR코드, 숨겨진 관리자 설정(실가공 검증 승인).
- **검증 결과**: `V0.1/docs/테스트결과.md` 참조.
- **복원 기준**: `V0.1/pureun-ai-cam.html` 단일 파일만 있으면 실행 가능. 소스 복원 시 `V0.1/src/` 와 `build.mjs` 로 같은 HTML 을 다시 만들 수 있음 (`node build.mjs`). 사용자 데이터는 브라우저 저장소 또는 백업 JSON 파일에 있으며 버전 폴더와 무관.
