## V0.1 (2026-11-27)
- **기준**: 신규 프로젝트 최초 버전 (기존 원본 없음). 사용자 지시문에 명시된 버전명 "V0.1" 사용.
- **변경 사항**: 최초 개발 — FANUC 3축 2.5축 홀 가공(G81·G82·G73·G83·G84·M29 리지드 탭), 홀 배열(개별·직선·사각·PCD), 공정 묶음, 장비·공구 관리, 11개 항목 모델 검증 + 독립 NC 해석 검증, 오류 시 NC 생성 차단, 로컬 저장·JSON 백업/복원, 공유·QR코드, 숨겨진 관리자 설정(실가공 검증 승인).
- **검증 결과**: `V0.1/docs/테스트결과.md` 참조.
- **복원 기준**: `V0.1/pureun-ai-cam.html` 단일 파일만 있으면 실행 가능. 소스 복원 시 `V0.1/src/` 와 `build.mjs` 로 같은 HTML 을 다시 만들 수 있음 (`node build.mjs`). 사용자 데이터는 브라우저 저장소 또는 백업 JSON 파일에 있으며 버전 폴더와 무관.
