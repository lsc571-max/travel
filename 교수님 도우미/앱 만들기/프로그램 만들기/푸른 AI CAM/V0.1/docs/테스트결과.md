# 푸른 AI CAM V0.1 테스트 결과·문제점 (검증 보고서)

- 대상: `V0.1/` (2026-11-27). 이 보고서는 V0.1 소스를 바꾸지 않는다.
- 결론: 자동 테스트는 모두 통과했으나, **독립 검증에서 안전 결함 9건이 발견**되었다. 모두 **V0.2에서 수정**했다. **V0.1 대신 V0.2를 사용할 것.**

## 1. 자동 테스트 (모두 실제 실행)
| 구분 | 도구 | 결과 |
|---|---|---|
| 계산 엔진 단위 테스트 | Node.js 내장 테스트 러너 | 57 / 57 통과 |
| 브라우저 통합 테스트 (PC 1440px·모바일 390px·웹 배포) | Playwright + Chromium | 57 / 57 통과 |
| QR코드 판독 | jsQR | 앱 주소와 일치 |
| 코드 검사 | ESLint 9 (recommended) | 오류 0 |

개발 중 테스트로 찾아 고친 문제:
- 탭 기초 드릴 검사가 "마지막 드릴"만 보던 문제 → 직경이 맞는 드릴 중 가장 깊은 것으로 판정하도록 수정
- 모바일 화면 배치 깨짐 (CSS 우선순위) → 수정
