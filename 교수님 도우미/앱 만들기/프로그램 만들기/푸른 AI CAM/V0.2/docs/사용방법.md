# 푸른 AI CAM V0.1 사용 방법

FANUC 3축 머시닝센터용 **2.5축 홀 가공 CAM** 입니다. 설치 없이 웹 브라우저(윈도우 크롬·엣지)에서 실행되며, 인터넷 연결·서버·AI API 비용이 없습니다.

> ⚠ **안전 안내** — 이 프로그램의 자동 검증은 실제 가공 안전을 보장하지 않습니다. 실가공 검증이 끝나지 않은 장비용 NC 파일은 `TEST_` 파일명과 `(*** TEST ONLY ... ***)` 주석으로 표시됩니다. 처음 가공할 때는 반드시 **Z를 띄운 드라이런(공회전) → 싱글 블록 → 시편 가공** 순서로 작업자가 직접 확인한 뒤 가동하세요.

---

## 1. 실행

1. `pureun-ai-cam.html` 파일을 더블클릭합니다 (크롬 또는 엣지로 열림).
2. 처음 실행하면 예제 프로젝트(M6 탭 6개 + M5 탭 PCD 4개)가 열립니다.
3. 작업 내용은 **이 PC의 브라우저에 자동 저장**됩니다. 같은 브라우저로 다시 열면 그대로 이어서 작업할 수 있습니다.

> 브라우저의 "인터넷 사용 기록 삭제(쿠키·사이트 데이터)"를 하면 저장 데이터도 지워집니다. 정기적으로 **설정 → 전체 백업**을 하세요.

## 2. 화면 구성 (5분할)

| 영역 | 위치 | 내용 |
|---|---|---|
| ① 상단 메뉴 | 맨 위 | 프로젝트 이름, 프로젝트 목록, 되돌리기/다시 하기, **NC 다운로드**, 공유, 설정(⚙) |
| ② 설정 패널 | 왼쪽 | [소재·가공] [장비·공구] [공정 묶음] 탭 |
| ③ 그래픽 화면 | 가운데 | 소재·좌표계·격자·홀·클램프·가공 경로 표시, 마우스/터치로 홀 지정 |
| ④ 홀·공정 패널 | 오른쪽 | 홀 그룹, 공정(가공 순서), 홀 배열 입력, 홀 좌표 목록 |
| ⑤ 결과 패널 | 가운데 아래 | [검증 결과] [G코드] 탭 |

스마트폰·좁은 화면에서는 아래쪽 **설정 / 화면 / 홀·공정 / 검증·코드** 버튼으로 패널을 바꿉니다.

## 3. 작업 순서

### 3-1. 소재 설정 (왼쪽 [소재·가공])
- **재질**: 절삭 조건 자동 추천과 이상 조건 검사에 사용됩니다.
- **가로 X · 세로 Y · 두께 Z**: mm 단위. **Z0 = 소재 윗면**입니다.
- **공작물 원점**: 좌하단·좌상단·우하단·우상단·소재 중심 중 선택. 바꿀 때 "홀 위치 유지(좌표 자동 변환)" 여부를 묻습니다.
- **하부 여유(패럴렐 틈)**: 소재 아래 빈 공간(mm). 관통 가공 시 드릴 끝이 이 값보다 깊이 내려가면 **NC 생성이 차단**됩니다 (테이블·바이스 충돌 방지). 기본값 0.
- **NC 설정**: 프로그램 번호(O0001~O9999), 좌표계(G54~G59), 초기점 Z(안전 높이, 기본 50), 구멍 간 복귀(G98 초기점 = 안전 / G99 R점 = 빠름), 공정 순서(공구 교환 최소화 / 그룹 순서), 구멍 순서(최단 거리 / 지그재그 / 입력 순서), 절삭유, M01, 시퀀스 번호.
- **클램프·금지 영역**: 클램프 위치와 높이(Z0 기준)를 등록하면 홀 겹침, 초기점 높이, G99 이동 경로 충돌을 검사합니다.

### 3-2. 장비·공구 (왼쪽 [장비·공구])
- 장비별로 행정, 최대 회전수, 리지드 탭 최대 회전수, 최대 절삭 이송, 매거진 공구 수, 리지드 탭 지원 여부를 설정합니다.
- **공구 목록**: T번호, 종류(센터/스팟 드릴·드릴·탭), 직경(탭은 호칭경), 선단각 또는 피치, 재질(HSS/초경), 유효 날 길이.
- **미터 나사 기초 드릴 추천**: 호칭경과 피치를 넣으면 추천 드릴 직경을 보여 줍니다 (절삭 탭 기준).
- **적합성 확인**: 현재 장비·재질·소재 두께로 모든 공정 묶음을 점검합니다.
- 장비 설정을 바꾸면 그 장비의 "실가공 검증 완료" 승인이 자동으로 해제됩니다.

### 3-3. 홀 그룹과 공정 (오른쪽 패널)
**홀 그룹** = 같은 공정을 쓰는 홀들의 묶음입니다 (예: "M8 탭 4개").
1. **+ 홀 그룹 추가** → 이름 입력
2. **공정 묶음 적용**: 등록된 프리셋(예: "M8 탭 (깊이 15)")을 골라 [적용] → 스팟 드릴 → 기초 드릴 → 탭 공정이 한 번에 들어갑니다. 장비의 공구 번호가 다르면 같은 사양의 공구로 자동 매칭됩니다.
3. 공정을 직접 추가·수정할 수도 있습니다.

| 가공 방식 | 코드 | 비고 |
|---|---|---|
| 센터 드릴 | G81 (드웰 입력 시 G82) | 모따기 직경 자동 표시 |
| 일반 드릴 | G81 (드웰 입력 시 G82) | |
| 고속 펙 드릴 | G73 | Q = 1회 절입량 |
| 심공 드릴 | G83 | Q = 1회 절입량 (매번 R점 복귀) |
| 일반 탭 | G84 | 텐션·컴프레션 탭 홀더 필요 |
| 리지드 탭 | M29 S__ + G84 | 장비 리지드 탭 지원 필요 |

- **깊이 기준**: 드릴은 "공구 끝" 또는 "직경부(끝각 길이 자동 추가)" 중 선택. **관통**을 체크하면 소재 두께 + 관통 여유 + 끝각 길이가 자동 계산됩니다.
- **자동 추천**: 재질·공구 재질·직경으로 회전수(S)와 이송(F)을 계산합니다 (참고값, 공구 카탈로그 우선).
- **탭 이송**: 항상 **F = S × 피치** (G94, mm/min) 로 자동 계산되며 직접 입력할 수 없습니다.
- 각 공정 아래에 공구 끝 Z, 절삭속도 Vc, 회전당 이송, 기초 드릴 추천이 표시됩니다.

### 3-4. 홀 위치 지정
- **좌표 직접 입력**: [개별] X, Y → [홀 추가]
- **직선 배열**: 시작점, 간격, 각도, 개수
- **사각 배열**: 시작점, X/Y 간격, X/Y 개수
- **PCD 배열**: 중심, PCD 직경, 개수, 시작각
- **마우스/터치**: 화면 위 [＋ 홀 추가] 모드에서 클릭·터치 (스냅 간격에 맞춰 위치 보정)
- **수정**: 홀 목록에서 좌표 수정, [↖ 선택] 모드에서 홀을 끌어서 이동, Delete 키 또는 🗑 로 삭제
- 좌표는 모두 **공작물 원점 기준(mm)** 입니다.

### 3-5. 그래픽 화면 조작
| 동작 | 마우스 | 터치 |
|---|---|---|
| 확대/축소 | 휠, ＋/－ 버튼 | 두 손가락 벌리기/모으기 |
| 화면 이동 | 빈 곳 드래그, 오른쪽/가운데 버튼 드래그 | 두 손가락 이동, 빈 곳 드래그 |
| 전체 보기 | [맞춤] | [맞춤] |
| 홀 선택·이동 | 클릭·드래그 ([선택] 모드) | 터치·드래그 |
| 클램프 추가 | [▭ 클램프] 모드에서 드래그 | 동일 |

- **경로·순서**: 공정별 가공 순서(번호·화살표)를 표시합니다. 드롭다운에서 공정을 고르면 그 공정만 보입니다.
- **NC 해석**: 생성된 G코드를 독립 검증기가 다시 해석한 위치(× 표시)와 이동 경로를 겹쳐 보여 줍니다.
- 빨간 테두리 = 오류가 있는 홀, 주황 테두리 = 경고가 있는 홀.

### 3-6. 검증 결과 확인 (아래 [검증 결과])
- **11개 항목 모델 검증**: 좌표, 소재 범위, 중복·간섭 홀, 공구 번호·종류, 탭 기초 드릴, 절삭 조건, 탭 이송·장비 지원, 가공 깊이, 펙·사이클 조건, 안전 높이·충돌, NC 구조·장비 설정.
- **독립 NC 해석 검증**: 생성된 G코드를 별도 해석기로 한 줄씩 시뮬레이션하여 문법·이동 경로·충돌을 다시 검사하고, 생성기 계산 결과와 구멍 위치·깊이가 100% 일치하는지 교차 확인합니다.
- **5단계 검증 절차** 상태 표시: ① 코드 알고리즘 ② NC 문법 ③ 이동 경로 ④ 입력값 한계 ⑤ 실장비 테스트.
- 메시지를 누르면 해당 홀이 선택되거나 G코드의 해당 줄로 이동합니다.
- **오류(✖)가 하나라도 있으면 NC 파일 생성이 차단**됩니다. 경고(⚠)는 확인 후 진행할 수 있습니다.

### 3-7. G코드 확인·수정·다운로드 (아래 [G코드])
- 설정이 바뀌면 G코드가 자동으로 다시 만들어집니다. [⧉ 복사]로 복사할 수 있습니다.
- **[✎ 직접 수정]**: 수정하는 순간 기존 검증이 무효화됩니다. 수정 후 **[✔ 수정본 재검증]** 을 눌러 오류가 없어야 다운로드할 수 있습니다. 텍스트를 다시 고치면 다시 재검증해야 합니다. 수정본에는 `(USER EDITED - REVERIFIED 날짜)` 주석이 붙고 파일명 끝에 `_EDIT`가 붙습니다.
- **[⟳ 다시 생성]**: 수정 내용을 버리고 현재 설정으로 다시 생성합니다.
- **NC 다운로드**: 파일명 `O0001_이름.nc` (미검증 장비는 `TEST_O0001_이름.nc`), 윈도우 줄바꿈(CRLF). 다운로드 전에 안전 확인 창이 나옵니다.
- NC 주석은 FANUC 호환을 위해 **영문 대문자·숫자만** 출력됩니다 (한글 프로젝트 이름은 주석에서 제외).

## 4. 공정 묶음 (왼쪽 [공정 묶음])
- 자주 쓰는 공정(예: M6 탭 = 스팟 → Ø5 펙 드릴 → M6 리지드 탭)을 프리셋으로 등록합니다.
- [편집]에서 이름·설명·공정 순서(↑↓)·조건을 수정합니다. 묶음 목록 순서도 ↑↓로 바꿀 수 있습니다.
- 홀 그룹의 현재 공정을 [현재 공정을 묶음으로 저장]으로 등록할 수 있습니다.
- [⬇ 내보내기] / [⬆ 가져오기]: JSON 파일로 다른 PC와 주고받습니다.
- [적합성 확인]: 재질·두께·장비가 바뀌었을 때 각 묶음이 그대로 쓸 수 있는지(공구 존재, 깊이, 회전수 한계 등) 점검합니다.

## 5. 프로젝트·백업
- **📁 프로젝트**: 새 프로젝트, 열기, 복제, 삭제, 파일로 내보내기(.pcam.json), 파일 가져오기.
- **⚙ 설정 → 전체 백업**: 프로젝트·공정 묶음·장비·공구를 한 파일로 저장합니다. **백업 복원** 시 현재 데이터를 먼저 자동 백업합니다.
- 다른 PC에서 가져온 장비의 "실가공 검증 완료" 승인은 보안상 해제되며, 관리자가 다시 승인해야 합니다.

## 6. 설정
- **⚙ 설정 버튼 1회 클릭**: 일반 설정 (테마, 글자 크기, 경고음, 언어, 공유·QR코드, 버전·업그레이드, 백업·복원).
- 앱 공유는 웹 서버에 배포된 주소에서만 링크·QR코드를 제공합니다. 로컬 파일로 실행 중이면 HTML 파일 자체를 전달하라는 안내가 나옵니다.

## 7. 관리자 설정 (장비 실가공 검증 승인)
- 일반 설정 창 제목 옆의 **⚙ 아이콘을 3초 안에 5번 연속 클릭(또는 터치, 키보드 Enter)** 하면 관리자 인증 창이 열립니다. 키보드 사용자는 **Alt + Shift + A** 로도 열 수 있습니다 (비밀번호는 동일하게 필요).
- 처음에는 **이 기기 전용 관리자 비밀번호**를 등록합니다 (8자 이상, 영문+숫자). 비밀번호 원문은 저장하지 않고 PBKDF2-SHA256 해시만 저장합니다.
- 5회 틀리면 5분간 잠깁니다. 창을 닫거나 10분이 지나면 관리자 모드가 끝나고 다시 인증해야 합니다.
- 관리자 기능: **장비 실가공 검증 승인/해제** (드라이런·싱글 블록·시편 가공 3가지 확인 + 확인자 필수), 비밀번호 변경, 전체 데이터 초기화.
- 비밀번호를 잊으면 인증 창의 "비밀번호 재설정"을 사용합니다. 재설정하면 모든 장비의 실가공 승인도 함께 해제됩니다.
- 이 웹앱은 서버가 없어 관리자 보호는 **이 PC 브라우저 안에서만** 동작합니다. PC 계정 보안(윈도우 로그인 비밀번호)을 함께 관리하세요.

## 8. 첫 실가공 절차 (권장)
1. 장비의 공구 번호·직경·날장을 실제 매거진과 일치시킵니다.
2. 리지드 탭 사용 시 장비 매뉴얼에서 M29 사용 방식(주축 정지 상태 필요 여부, 파라미터)을 확인하고 [리지드 탭 전 S__ M03 출력] 옵션을 맞춥니다.
3. NC 파일을 장비로 전송한 뒤 **공작물 좌표계 Z를 +50mm 이상 띄워 드라이런**합니다.
4. **싱글 블록**으로 공구 교환, G43 보정, 첫 구멍 위치를 확인합니다.
5. 시편을 가공하여 위치·깊이·나사 게이지를 확인합니다.
6. 관리자 설정에서 해당 장비를 "실가공 검증 완료"로 승인합니다.
