# 푸른 AI CAM V0.3 검증 보고서

- 대상 버전: **V0.3** (`교수님 도우미/앱 만들기/프로그램 변경하기/푸른 AI CAM/V0.3/`)
- 변경 전 버전: V0.2 (`교수님 도우미/앱 만들기/프로그램 만들기/푸른 AI CAM/V0.2/`, 보존)
- 검증일: 2026-11-27
- 검증 환경: Linux 컨테이너, Node.js 22, Playwright + Chromium. 윈도우 크롬·엣지와 실제 FANUC 장비는 사용하지 않았다.
- 결론: 자동 검증과 독립 검증에서 나온 결함 8건을 모두 고쳤고, 재현 스크립트로 해결을 확인했다. **실장비 검증 전이므로 출력 NC는 계속 "검증용(TEST)"이다.**

## 5. 원본·기존 기능 영향
- V0.1, V0.2 폴더는 변경하지 않았다. V0.1에는 검증 보고서만 이전에 추가했다.
- 기존 기능은 모두 유지된다: 직접 구성, 공정 묶음, 배열, 클램프, 검증·차단, 관리자, 공유, 백업.
- 데이터 형식은 같다(schema 1). V0.3 파일을 V0.2에서 열면 간편 입력 정보는 무시되고 공정은 그대로 남는다.
- **동작이 바뀐 점(안전 강화)**:
  - D1보다 작은 기초 드릴은 이제 오류로 처리한다. 예전에는 경고만 했거나 통과했다.
  - 관통 여유 0.5mm 미만은 차단한다.
  - 관통 탭 출구가 짧으면 경고한다.
