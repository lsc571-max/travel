# Google Cloud 새 프로젝트 만들기 안내 (처음 1회, 약 15분)

푸른 교수 일정관리 앱이 구글 캘린더에 접속하려면 **OAuth 클라이언트 ID** 하나가 필요합니다.
아래 순서대로 하시면 됩니다. 결제 정보(신용카드)는 **필요 없습니다.**

> 화면 메뉴 이름은 Google이 자주 바꿉니다. 이름이 조금 달라도 같은 위치의 메뉴를 찾으시면 됩니다.

---

## 1단계. 새 프로젝트 만들기
1. https://console.cloud.google.com 접속 (lsc571 계정)
2. 화면 위쪽 **프로젝트 선택** → **새 프로젝트**
3. 프로젝트 이름: `pureun-schedule` → **만들기**
4. 만들어지면 위쪽에서 `pureun-schedule` 프로젝트가 선택되어 있는지 확인

## 2단계. Google Calendar API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. 검색창에 `Google Calendar API` → 선택 → **사용**

## 3단계. 로그인 화면(OAuth 동의 화면) 설정
1. 왼쪽 메뉴 **Google 인증 플랫폼**(또는 **OAuth 동의 화면**) → **시작하기**
2. 앱 이름: `푸른 교수 일정관리`, 사용자 지원 이메일: 본인 Gmail
3. 대상(사용자 유형): **외부**
4. 연락처 이메일: 본인 Gmail → 동의 후 **만들기**
5. **대상(Audience)** 메뉴: 게시 상태는 **테스트** 그대로 두고, **테스트 사용자 → 사용자 추가**에 본인 Gmail 주소 입력 → 저장
6. **데이터 액세스** 메뉴 → **범위 추가 또는 삭제** → `.../auth/calendar.events` 체크 → 업데이트 → 저장

> 테스트 상태에서는 등록한 테스트 사용자(본인)만 로그인할 수 있습니다. 개인용으로는 이것으로 충분합니다.
> 테스트 상태에서는 일정 기간(보통 7일)마다 권한 동의 화면이 다시 나올 수 있습니다. 불편하면 나중에 "앱 게시"로 바꾸면 됩니다.

## 4단계. 클라이언트 ID 만들기
1. **Google 인증 플랫폼 → 클라이언트** → **클라이언트 만들기**
2. 애플리케이션 유형: **웹 애플리케이션**, 이름: `일정관리 웹앱`
3. **승인된 JavaScript 원본**에 다음을 추가
   - `https://pureun-schedule.web.app`
   - `https://pureun-schedule.firebaseapp.com`
   - (PC에서 시험할 때만) `http://localhost:5173`
   - ※ 프로젝트 ID가 `pureun-schedule`과 다르게 만들어졌다면 그 ID로 바꿔 넣으세요.
4. **승인된 리디렉션 URI는 비워 둡니다** (이 앱은 팝업 방식이라 필요 없음)
5. **만들기** → 나타난 **클라이언트 ID**(`숫자-영문.apps.googleusercontent.com`)를 복사

> ⚠ 함께 표시되는 **클라이언트 보안 비밀번호(secret)는 이 앱에서 쓰지 않습니다.** 어디에도 붙여넣지 마세요.
> 클라이언트 ID는 공개되어도 되는 식별자이지만, 승인된 원본(위 주소)에서만 동작합니다.

## 5단계. 앱에 입력
1. 앱 열기 → 상단 안내의 **관리자 설정 열기** (또는 설정 ⚙ → 톱니바퀴 아이콘 3초 안에 5번)
2. 처음이면 관리자 비밀번호 등록 (4자 이상, 이 기기에만 저장)
3. **OAuth 클라이언트 ID** 칸에 붙여넣기 → **저장하기** → **연결 테스트**
4. "연결 성공"이 나오면 완료

스마트폰·태블릿에서는 각 기기에서 5단계를 한 번씩 해 주세요. (클라이언트 ID를 앱에 미리 넣어 배포하면 이 과정 없이 "구글 연결"만 누르면 됩니다 — 원하시면 클라이언트 ID를 알려 주세요.)

---

## 6단계. Firebase Hosting 배포 (인터넷 주소 만들기)
1. https://console.firebase.google.com → **프로젝트 추가** → **기존 Google Cloud 프로젝트에 Firebase 추가** → `pureun-schedule` 선택
2. Google 애널리틱스는 **사용 안 함** → 완료 (요금제는 무료 Spark 그대로)
3. PC에 Node.js(LTS) 설치 후, 이 폴더에서:
   ```
   npm install
   npm run build
   npx firebase-tools login
   npx firebase-tools deploy --only hosting --project pureun-schedule
   ```
4. 배포 주소: `https://pureun-schedule.web.app`

## 문제가 생기면
| 증상 | 원인·해결 |
|---|---|
| `origin_mismatch` / "승인되지 않은 원본" | 4단계 3번에 현재 주소가 정확히 등록됐는지 확인 (끝에 `/` 없이) |
| `access_denied` / "앱이 확인되지 않음" 후 차단 | 3단계 5번 테스트 사용자에 본인 Gmail이 있는지 확인 |
| 403 "Calendar API has not been used" | 2단계 Calendar API 사용 설정 확인 |
| 로그인 팝업이 안 뜸 | 브라우저 팝업 차단 해제 |
